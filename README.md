# Code-a-day
Code a day is a simple website which asks you questions and at the end of the day it gives out a day routine for you and then it also gives a playlist which reflects your day.

## Code-a-day
A little fun interaction to have at the end or the start of your day to keep your mind fresh.

## How it works?
You start with the main page, and then you have the option to chose between 3 categories. Then you chose a character. After that you answer questions for 4 part of the day, morning, afternoon, evening and night. Afterwards your day is summarised in front of you and then you get a custom playlist made based on your choices.

## Features
-Interactive question cards
-Character selection
-Morning, afternoon, evening and night
-Final day summary
-Personalised playlist

## Spotify API Integration
Once you have your day ready, you get an option to make a playlist which uses spotify API and make you a custom playlist using spotify
